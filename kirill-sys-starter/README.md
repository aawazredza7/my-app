# Кирилл Сыс — стартовый прототип

Это первый интерфейсный прототип: настройки имени/промта/голоса сохраняются в браузере, озвучка использует установленные русские голоса Windows, а текстовый чат подключается к локальной Ollama.

## Что нужно

- Windows 10/11
- 16 ГБ RAM желательно
- Ollama: https://ollama.com/download
- Современный браузер (Edge рекомендуется)

## Запуск прототипа

1. Установи Ollama.
2. Открой PowerShell и выполни:

   ```powershell
   ollama pull qwen3.5:9b
   ```

3. Скачай и распакуй архив.
4. В папке проекта запусти `start.bat`.
5. Открой `http://localhost:4173` в Edge.

Если браузер блокирует запросы к Ollama из-за CORS, закрой Ollama из системного трея, затем в PowerShell выполни:

```powershell
$env:OLLAMA_ORIGINS="http://localhost:4173"
ollama serve
```

Если Ollama уже работает как фоновое приложение, сначала полностью заверши его через значок в системном трее. После этого обнови страницу.

## Что уже работает

- Редактирование имени персонажа.
- Редактирование системного промта.
- Сохранение настроек в localStorage.
- Выбор доступного русского голоса Windows/браузера.
- Проверка выбранного голоса.
- Отправка сообщений в локальную модель Ollama.
- Озвучивание ответов.

## Чего пока нет

- Реального захвата экрана и понимания игры.
- Распознавания микрофона.
- Автоматических реплик без вопроса пользователя.
- Нативного Windows-инсталлятора.
- Защищённого backend-слоя.

Это намеренно первый маленький этап. Следующий шаг — перенести интерфейс в Tauri 2, чтобы получить полноценное Windows-приложение и безопасно подключить микрофон, экран и локальный ИИ.


## Обновление v0.2 — характер и экономия ресурсов

- Более разговорный системный промт «кореш из Discord»: юмор, лёгкие подколы, разговорный стиль, без навязчивого позитива и официоза.
- Спокойный однотонный графитовый дизайн без неоновых градиентов.
- Модель по умолчанию уменьшена до `qwen3.5:9b` для меньшей нагрузки на ПК (качество ответов может быть ниже, чем у 3B).
- Ограничен контекст последними 10 сообщениями, окно контекста 2048 токенов.
- Модель выгружается после 2 минут простоя (`keep_alive`).

Чтобы применить новый характер, открой настройки и нажми «Сохранить настройки». Если в браузере уже сохранён старый промт, замени его текстом из поля настроек или очисти данные сайта для localhost:4173.


## Обновление v0.3 — характер + голосовой режим

- Новый характер: хаотичный юмор, мемы, дружеские подколы, свободный мат к месту, без постоянного позитива.
- Кнопка голосового режима: распознавание русской речи через SpeechRecognition в Microsoft Edge/Chromium.
- Ответы озвучиваются через системный синтез речи.
- Активная инициатива: во время включённого голосового режима после периода тишины модель может сама предложить короткую реплику по контексту беседы. Это экспериментальная функция: небольшая локальная модель может иногда молчать или выдавать неидеальные инициативные фразы.
- Микрофон используется только после явного включения голосового режима. Выключение режима останавливает распознавание и речь.

### Важно
Web Speech Recognition в Edge может использовать встроенный онлайн-сервис распознавания речи и не гарантирует полностью офлайн-работу. Для действительно локального распознавания следующим этапом подключим whisper.cpp. Для голосового режима открой страницу в Microsoft Edge и разреши доступ к микрофону.


## Обновление v0.3.1 — характер без «техподдержки»

- Усилен стандартный промпт: Кирилл общается на равных, может спорить, шутить и быть прямым, без приторной доброты.
- Добавлены постоянные правила стиля, которые добавляются к системному сообщению отдельно. Поэтому старый промпт из `localStorage` больше не отключает новые правила поведения.
- Мат, ругань и грубоватый тон в обычной беседе сами по себе не должны запускать нотации или шаблонный отказ.
- Добавлена кнопка «Загрузить характер кореша» для возврата к рекомендуемому тексту промпта. После нажатия нужно сохранить настройки.
- Серьёзные темы по-прежнему обрабатываются спокойно; реальные ограничения безопасности не отключаются.

### Важно про модель
В этой версии используется `qwen3.5:9b` (это видно в `src/app.js`). Маленькая модель может не всегда точно следовать длинным инструкциям. Если характер всё ещё «плывёт», качество модели будет следующим ограничением; сам промпт не может гарантировать поведение, которое модель не умеет стабильно выполнять.


## Обновление v0.4 — новый характер и новая модель

- Вместо Qwen2.5 1.5B используется Qwen3.5 9B 2507 в 4-битной квантизации.
- Модель выбрана под ПК с 16 ГБ ОЗУ и видеокартой с 6 ГБ VRAM; Ollama может распределять вычисления между видеокартой и процессором.
- Упрощён и усилен характер Кирилла: разговор на «ты», естественные короткие ответы, юмор и разрешённый мат без офисных отказов.
- Температура снижена до 0.85, контекст увеличен до 4096 токенов.
- Исправлена проверка подключения к Ollama: приложение проверяет доступность API и наличие выбранной модели.
- Если в браузере был сохранён старый стандартный промпт, он автоматически заменяется обновлённым. Пользовательский промпт не затирается.

Установка новой модели (выполняется один раз):

```powershell
ollama pull qwen3.5:9b
```

Если Ollama уже запущена, после загрузки модели просто обнови страницу приложения. Старую модель удалять необязательно; если захочешь освободить место, после проверки новой можно выполнить `ollama rm qwen2.5:1.5b`.


## Обновление v0.5 — переход на Qwen3.5 9B

- Модель по умолчанию переключена на `qwen3.5:9b` (она уже установлена, если список Ollama из проверки актуален).
- Уточнены правила: отвечать на вопрос по существу, не выдумывать игровые предметы и механики, переспрашивать при ошибках распознавания речи.
- Если компьютер будет отвечать слишком медленно или сообщит о нехватке памяти, модель можно вернуть на Qwen3 4B в `src/app.js`.


## Обновление — локальная память Кирилла

- В настройках появилось поле «Память Кирилла»: сюда можно записать факты и предпочтения, которые модель будет видеть в новых ответах.
- Можно написать в чат «Запомни: ...» — заметка добавится в локальную память автоматически.
- Память хранится в localStorage браузера на этом компьютере и не отправляется в облако. Очистить её можно, удалив текст в поле и нажав «Сохранить память».
- Это простая управляемая память: Кирилл пока не извлекает факты из каждой беседы автоматически.


## Обновление — поиск в интернете

- Запуск теперь идёт через `server.py`, а не встроенный статический сервер.
- Фраза «найди …», «поищи …», «проверь в интернете …» или «что нового …» запускает поиск DuckDuckGo через локальный Python-сервер.
- Найденные заголовки и ссылки передаются модели как контекст; ссылки на источники отображаются под ответом.
- Для поиска нужен доступ в интернет. Используется DuckDuckGo HTML без API-ключа; доступность зависит от того, не ограничивает ли сервис запросы.
- Обычные сообщения не отправляются в поисковик. Поиск запускается только по явной команде/формулировке.


### Предложения памяти

Кирилл может сам предложить сохранить устойчивый факт, интерес или предпочтение, добавив карточку «Могу запомнить» под ответом. Запись происходит только после нажатия «Запомнить»; «Не надо» закрывает предложение. Чувствительные данные и одноразовые детали не должны предлагаться к сохранению. Пользователь по-прежнему может вручную управлять всей памятью в настройках.


## Обновление — контекст, голос и действия

- Последние 30 реплик диалога сохраняются в localStorage и восстанавливаются после перезагрузки страницы. В запрос к модели передаются последние 10 реплик, чтобы не раздувать контекст.
- Кнопка «Стоп речи» останавливает озвучку; начало распознанной реплики с микрофона также перебивает текущую озвучку.
- Кирилл может сам начать короткую реплику во включённом голосовом режиме после трёх минут тишины, если в истории уже есть хотя бы три сообщения пользователя. За одну паузу он делает не больше одной попытки; после новой реплики пользователя ожидание начинается заново. Может ненавязчиво вернуться к теме из категории «Незаконченные темы», если она подходит к разговору. Если повода нет, он молчит. Это не работает в обычном текстовом режиме.
- Если пользователь прямо просит открыть сайт, Кирилл может показать кнопку подтверждения. Сайт открывается только после нажатия; произвольные команды и запуск программ через этот механизм не выполняются.
- Поиск по-прежнему запускается по явному запросу и показывает ссылки на найденные страницы. Это экспериментальный поиск DuckDuckGo, а не гарантированная проверка достоверности.
- Никаких отдельных игровых режимов нет: Кирилл общается в одном общем контексте и может обсуждать любые темы.


## Скорость ответа и выбор модели

- Ответ теперь отображается потоком: текст появляется по мере генерации Ollama, а не после завершения всего ответа. Это уменьшает ощущаемое ожидание, но не увеличивает скорость самой модели.
- В настройках можно выбрать установленную модель. Для более быстрой реакции попробуй Qwen3 4B; Qwen3.5 9B обычно даёт более содержательные ответы, но на видеокарте с 6 ГБ VRAM может частично работать через CPU и отвечать медленнее.
- В списке недоступные в Ollama модели отключаются. Выбор сохраняется вместе с настройками.

## Обновление — живой характер и серьёзность по просьбе

- У Кирилла один характер для всех тем и игр; отдельных игровых режимов нет.
- По умолчанию он общается свободно: может импровизировать, шутить, придумывать очевидную абсурдную чушь и подхватывать угар.
- При этом выдумки не должны маскироваться под реальные факты: конкретные игровые предметы и механики, цифры, инструкции и сведения о реальном мире остаются фактическими.
- Фраза «давай серьёзно», «без шуток» или «включи серьёзный режим» включает вдумчивый режим. Кирилл внимательнее проверяет расчёты, логику и допущения, не придумывает недостающие данные и меньше шутит.
- Фраза «верни обычный режим», «можно шутить» или «хватит серьёзничать» возвращает привычную манеру.
- Выбранный режим сохраняется локально в браузере. Индикатор текущего режима показывается под чатом.
- В запрос Ollama передаются последние 10 реплик, чтобы ограничивать объём контекста.

### Быстрая проверка поведения

1. Напиши «придумай самую нелепую причину, почему Рошан сегодня не вышел на работу» — в обычном режиме ответ может быть абсурдным и смешным.
2. Напиши «давай серьёзно: рассчитай, сколько ресурсов нужно для ...» — Кирилл должен перейти к расчётам и показать допущения.
3. Напиши «верни обычный режим» — юмор и свободная манера снова разрешены.
4. Обсуди реальный предмет Dota 2 или механику X4 — даже в обычном режиме Кирилл не должен выдавать выдумку за настоящую игровую информацию.

## Обновление — игровые названия и шутки про предметы Dota 2

- Кирилл может по-своему обыгрывать узнаваемые названия настоящих предметов: например, «Священный меч (Divine Rapier)».
- Иногда допустимы выдуманные, но правдоподобные шуточные предметы с названием и эффектом в духе Dota 2. Такие шутки используются редко и к месту, а не превращаются в постоянный поток фальшивых предметов.
- Если пользователь просит настоящую сборку, актуальные предметы или точные игровые механики, Кирилл использует только реальные данные и не выдаёт выдумки за существующие предметы.

## Обновление — общая память Кирилла

Память теперь задумана в трёх категориях:

- **О пользователе:** устойчивые интересы, предпочтения, проекты и полезный контекст.
- **Наши приколы:** повторяющиеся внутренние шутки, прозвища, смешные истории и фразы, которые действительно стали общими мемами.
- **Незаконченные темы:** планы, проекты и вопросы, к которым пользователь собирается вернуться.

Кирилл предлагает не более одной заметки за раз. Случайные шутки не записываются как мемы, а тема не считается незаконченной без признака, что к ней хотят вернуться. Сохранение по-прежнему происходит только после нажатия «Запомнить». Подходящие воспоминания можно ненавязчиво использовать в будущих беседах, не повторяя их постоянно.

## Обновление — менеджер памяти

В настройках память разделена на три категории: «О пользователе», «Наши приколы» и «Незаконченные темы». Заметки можно добавлять вручную, редактировать и удалять по отдельности. Старые текстовые записи автоматически подхватываются как заметки о пользователе при первом открытии новой версии. Предложения Кирилла о сохранении по-прежнему требуют подтверждения кнопкой. Данные остаются в localStorage текущего браузера и не синхронизируются между устройствами.


## Обновление v0.7 — понимание экрана

- Над полем ввода появилась кнопка «Показать экран». Браузер попросит явно выбрать весь экран, окно или вкладку и разрешить демонстрацию.
- Пока показ включён, при каждом отправленном сообщении приложение делает один JPEG-снимок выбранного источника и прикладывает его к запросу Ollama. Непрерывная запись или отправка кадров в фоне не ведётся.
- Для анализа изображений выбери мультимодальную модель Qwen3.5 9B. Остальные модели из списка не предназначены для понимания картинок.
- Остановить показ можно кнопкой в чате или штатной кнопкой браузера. При закрытии демонстрации статус обновляется автоматически.
- Снимки экрана не сохраняются в истории чата и localStorage; они передаются только локальному Ollama API на этом компьютере.
- Захват работает в актуальных Edge/Chrome через localhost. Содержимое экрана может включать личные данные — делись только тем окном, которое готов показать модели.


## Оптимизация для слабой видеопамяти

- Запросы к Ollama выполняются последовательно: голосовое распознавание больше не запускает параллельные генерации поверх уже работающей модели. Самостоятельная реплика Кирилла пропускается, если модель уже занята.
- В обычный запрос передаются последние 10 реплик вместо 12.
- Контекст Ollama уменьшен с 4096 до 3072 токенов — это сокращает расход памяти под контекст, но оставляет меньше места для длинной истории.
- `keep_alive` уменьшен с 5 до 2 минут: после паузы Ollama раньше освобождает память модели. Следующий ответ после долгого простоя может начинаться медленнее из-за повторной загрузки.
- Захват экрана запрашивает до 1 кадра/с; это не означает отправку кадров модели каждую секунду. Снимок по-прежнему делается только при отправке сообщения.
- Перед отправкой снимок уменьшается до ширины 1024 пикселя и сжимается в JPEG с качеством 0.72.
- Если в фоне запущены другие GPU-приложения или игра, лучше выключать показ экрана, когда он не нужен.

Настройки подобраны как умеренный компромисс для видеокарты с 6 ГБ VRAM. Фактическую загрузку GPU/CPU и скорость ответа нужно проверить на конкретном компьютере через Диспетчер задач Windows и сравнить до/после.
